Présentation du projet

Ce projet s'inscrit dans le cadre de l'épreuve E6 "Parcours de Professionnalisation" du BTS SIO. L'objectif était de déployer une solution de gestion de parc informatique (GLPI) sur une machine virtuelle pour répondre aux besoins d'une organisation fictive.

Le projet a permis de mettre en pratique les compétences acquises en administration système, virtualisation et gestion de parc, tout en respectant les contraintes techniques et pédagogiques de l'épreuve.

Architecture technique

L'infrastructure repose sur une machine virtuelle Debian hébergée sous VirtualBox, avec les composants suivants :

Serveur GLPI

Version 10.0.10 installée sur une VM Debian 12 avec Apache, PHP 8.2 et MariaDB.

Virtualisation

VirtualBox 7.0 utilisé pour créer une VM avec 2 vCPU, 4 Go de RAM et 30 Go de stockage.

Base de données

MariaDB 10.11 pour stocker les données du parc informatique et des utilisateurs.

Étapes de déploiement

  1. Préparation de l'environnement — Installation de Debian 12 sur VirtualBox avec configuration réseau (NAT + Host-only).
  2. Installation des dépendances — Mise en place d'Apache, PHP 8.2, MariaDB et des extensions nécessaires.
  3. Configuration de GLPI — Téléchargement, extraction et configuration initiale via l'interface web.
  4. Création de la base de données — Import du schéma SQL et configuration des identifiants.
  5. Sécurisation du serveur — Configuration des pare-feux, mises à jour système et sauvegardes automatiques.
  6. Tests et validation — Vérification du bon fonctionnement des fonctionnalités principales (inventaire, tickets, gestion des utilisateurs).

Défis techniques rencontrés

Plusieurs obstacles ont été surmontés lors de ce projet :

  • Problème de permissions — Résolu en configurant correctement les droits Apache sur les dossiers GLPI.
  • Conflits de versions PHP — Solution : mise à jour vers PHP 8.2 et installation des extensions manquantes.
  • Sauvegardes non fonctionnelles — Identification d'un problème de quota disque, corrigé via la configuration de LVM.
  • Performances limitées — Optimisation de la VM (ajout de RAM, configuration du cache) pour une meilleure réactivité.
